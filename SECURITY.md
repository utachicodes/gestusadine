# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GëstuSaDine, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email: [utachicodes@users.noreply.github.com](mailto:utachicodes@users.noreply.github.com)

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (if applicable)

## Response

- We will acknowledge receipt within 48 hours
- We will provide a timeline for the fix within 7 days
- We will credit reporters in the changelog (unless you prefer to remain anonymous)

## Scope

This applies to:
- The GëstuSaDine web application
- The Convex backend functions
- The AI Council chatbot

## Out of Scope

- Third-party services (Convex, Vercel, Fanar API)
- Social engineering attacks
- Denial of service attacks
